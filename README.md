## About me

Industrial Design Engineer and software developer focused on automating manufacturing processes. I come from industrial and operations environments, where time and quality matter — that gave me the judgment to spot real bottlenecks: manual reports, inconsistent data, repetitive tasks and systems nobody wants to use.

Today I build web platforms, Python tools and desktop applications that are actually used in operations, currently as an external developer for American Axle projects through Comunicación Global. I get involved from understanding the process and detecting the problem all the way to implementing and supporting the solution.
